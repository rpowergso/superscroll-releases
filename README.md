# SuperScroll

Watch TikTok, Instagram Reels, and YouTube Shorts side by side in a desktop app. Arrange up to nine panels, use separate accounts, and choose custom shortcuts for each feed.

**[Download SuperScroll 2.14.1 beta](https://github.com/rpowergso/superscroll-releases/releases/tag/v2.14.1-beta)**

## Get started

- **Windows x64.** Extract the entire ZIP to a folder and open **SuperScroll.exe**. Windows may display an unknown-publisher warning because this beta is unsigned.
- **macOS preview.** Open the DMG and drag **SuperScroll** into Applications. The build includes Apple silicon and Intel support and was launch-tested on Apple silicon. Apple has yet to notarize it, so Gatekeeper may block it. [Apple’s guide to macOS app alerts](https://support.apple.com/en-us/102445)
- **Linux x86-64.** Extract the entire `.tar.gz` to a local folder, then run **superscroll** from that folder. This build was tested on Ubuntu with a graphical desktop.

Pick a layout, choose a site for each panel, and select **Start watching**. Try Guest mode or add a saved account profile. The app includes its runtime. To update, download a later release from this repository.

## What you can do

- Resize panels, repeat a site, and choose a different account per panel.
- Scroll, mute, set playback speed, or enable auto-advance independently for each feed.
- Use a long YouTube video in a panel alongside your short-video feeds.
- Start the next clip from a buffer when the site provides a playable clip in time.

## Accounts and privacy

Sign in on the platform’s own page. Saved profiles store site cookies and browser data locally. Different profiles are isolated, and guest sessions are temporary. The embedded websites control which videos and sign-in options are available. SuperScroll uses Cloudflare DNS over HTTPS by default for its own connections.
